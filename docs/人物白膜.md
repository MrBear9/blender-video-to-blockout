# 人物白膜：方案与当前进展

> 目标：从视频里做出人物的三维白模（简化几何体）。
> 与场景白模不同，人物的难点在于「主体本身在动」。

---

## 一条流水线，两段并行

```
视频 / 图片序列
      │
      ├──────────────┬──────────────┐
      ↓              ↓              ↓
   A. 解相机      B. 检测人物      时间对齐
  (COLMAP)      (YOLO / HOG / 差分)
      │              │
      └──────┬───────┘
             ↓
        三角化（多机位）
             ↓
      每帧的三维包围盒
             ↓
      Blender 里装配 / 验收
```

**A 和 B 不是二选一，它们在同一条链上。**
A 给出「相机在哪、朝哪看」，B 给出「人在画面里的哪块」，
三角化把这两样合成「人在三维空间里的哪」。

---

## A：换场景

### 已经验证成功的：TUM 室内桌面

```
注册帧数:        40/40
三维点:          2382
相机位姿误差:    1.86 厘米（对官方 groundtruth）
相对误差:        0.21%
```

**为什么成**：桌面上有大量静态可追踪物体，SIFT 特征充足且跨帧稳定。

### 失败的：AIST 白墙舞蹈

```
单机位移动相机:  780 对图，0 对解出本质矩阵
                 config=6（退化）×736  ← 纯旋转，无平移

三机位 c03/c05/c07:
    注册 72/72 帧，1015 点
    但相机几何是错的（见下）
```

**三机位的问题**：

```
cam0 与 cam1 相距  0.44
cam0 与 cam2 相距 11.81
cam1 与 cam2 相距 12.15

三个相机的朝向差: 1.4° / 1.5° / 2.9°   ← 几乎完全相同
```

**位置相距 12 个单位、朝向差 3 度**，这在物理上说不通。
画面明明不同（cam2 能看到卷帘门，cam0 看不到），
但解出来的相机朝向却几乎一样。

**结论**：这次重建的相机位姿不可用。
三角化结果 z 坐标 -45~-21（人跑到几十米外），残差 3.8。

## B：换方法 —— 只做人，不做全场

### 已经做出来的

**`detect_person.py`** —— 三种后端：

| 后端 | 依赖 | 精度 | 状态 |
|---|---|---|---|
| yolo | ultralytics | 高 | 代码就绪，待装 |
| hog | opencv | 中 | 代码就绪，待装 |
| **diff** | **无** | 这场景很好 | **已验证** |

`diff` 后端假设机位固定，用所有帧的中值当背景，
跟当前帧做差，最大连通块就是人。

**实测（AIST 白墙舞蹈）**：

```
cam0: 24/24 帧命中，框宽 0.070~0.126，框高 0.394~0.462
cam1: 24/24 帧命中，框宽 0.095~0.157
cam2: 24/24 帧命中，框宽 0.087~0.133
```

生成的 mask 轮廓非常准，能看出舞蹈姿势。

**`triangulate_person.py`** —— 多机位三角化

输入各机位的二维框 + 相机参数，输出三维位置。
用最小二乘求多条射线的最近点。

**但**：喂给它错相机参数，出来的就是错的位置。

## 现在的卡点

**缺可靠的相机参数。**

- COLMAP 在 AIST 白墙上解出来的不可信
- 手工标定三个机位做不到
- AIST++ 项目公开了标定文件，但那需要另外下载

### 三条出路

**1. 用 AIST++ 的官方标定**

`https://google.github.io/aistplusplus_dataset/download.html`
提供了 `setting*.json`，9 个机位的内参外参都有。
有了这个，三角化不需要 COLMAP。

**2. 换有纹理的场景**

街头、陈设丰富的室内。背景有特征，COLMAP 能解准。

**3. 单机位 + 人体模型**

不用多机位，用单帧估计人体三维姿态（如 MediaPipe 的 3D landmarks），
再靠时间平滑。这条路不需要多机位标定，但精度受限。

---

## 建议的下一步

**优先 1，因为最省事且最可靠。**

拿到 AIST++ 的标定文件后：

```bash
# 1. 检测（已完成）
python detect_person.py data/dance/images data/det --backend diff

# 2. 三角化（用官方标定，不用 COLMAP）
python triangulate_person.py official_calib.json \
    data/det_cam0 0 data/det_cam3 3 data/det_cam5 5

# 3. 导入 Blender
#    person_track.json 里每帧一个盒子和位置
```
